# ar-polygon

egxr.jsを使用したAR対応の3Dポリゴンエディタ。

## デモ
[ar-polygon demo](https://code4fukui.github.io/ar-polygon/)

## 機能
- ハンドトラッキングを使用して3Dポリゴンを作成、移動、削除
- ポリゴンの頂点をリアルタイムで調整
- VRおよび非VR環境の両方をサポート

## 動作環境
- WebXR対応ブラウザ（例: Oculus Browser 15.1+）
- ハンドトラッキング対応ハードウェア

## 使い方
1. WebXR対応ブラウザで[ar-polygon demo](https://code4fukui.github.io/ar-polygon/)を開きます。
2. プロンプトが表示されたら、WebXRとハンドトラッキングを有効にします。
3. 手を使用して3Dポリゴンを作成、移動、操作します。

## データ / API
このプロジェクトでは、WebXR機能のために[egxr.js](https://github.com/code4fukui/egxr.js/)ライブラリを使用しています。
