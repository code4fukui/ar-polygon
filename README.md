# ar-polygon

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

AR-enabled 3D polygon editor using egxr.js.

## Demo
[ar-polygon demo](https://code4fukui.github.io/ar-polygon/)

## Features
- Create, move, and delete 3D polygons using hand tracking
- Adjust polygon vertices in real-time
- Supports both VR and non-VR environments

## Requirements
- Compatible WebXR-enabled browser (e.g., Oculus Browser 15.1+)
- Supported hand-tracking hardware

## Usage
1. Open the [ar-polygon demo](https://code4fukui.github.io/ar-polygon/) in a compatible WebXR browser.
2. Enable WebXR and hand tracking when prompted.
3. Use your hands to create, move, and manipulate 3D polygons.

## Data / API
This project uses the [egxr.js](https://github.com/code4fukui/egxr.js/) library for WebXR functionality.
